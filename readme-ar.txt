تشغيل AH13 على Windows 11

1. اضغط بزر الماوس الأيمن على ملف ZIP واختر Extract All (استخراج الكل).
2. افتح index.html بالنقر المزدوج، أو شغّل Open-AH13.bat لفتحه في المتصفح الافتراضي.
3. لاختيار Edge أو Chrome، اضغط بزر الماوس الأيمن على index.html واختر Open with.
4. تحتاج التطبيقات الخارجية وروابط التواصل إلى اتصال بالإنترنت.

AH13 FINAL — حزمة النشر على GitHub Pages

1. فك الضغط وارفع جميع الملفات والمجلدات (بما في ذلك .nojekyll و google56674baa79267426.html) إلى المستودع على GitHub.
2. من إعدادات المستودع (Settings > Pages)، اختر الفرع الرئيسي (main) والمجلد الجذري (/root) ثم اضغط Save.
3. index.html هو الصفحة الرئيسية، وملف google56674baa79267426.html جاهز للتحقق في Google Search Console.
4. تم تحديث اللوجو والأيقونات الدائرية بشعار WEB & APP DEVELOPER الجديد، وإصلاح الوضع النهاري بالكامل مع حفظ تفضيلات اللغة والوضع.
5. تم الحفاظ على روابط التطبيقات الثمانية، وأرقام واتساب، وروابط فيسبوك من المعاينة الموافق عليها.
6. PWA يعمل بعد النشر عبر HTTPS. التخزين المؤقت يخص صفحات AH13 فقط وليس التطبيقات الخارجية.
